# 3-13：双级液压抬桥

原版游戏关卡 `3-13` 的内部名为 `2DeckerBoat`。2026-10-15 已在游戏中观察到「闯关成功」，造价 $30,355，预算 $32,000，最大接点压力 89.4%，材料体积 129.6 m。

![成功面板](../assets/verified/3-13-passed.jpg)

## 约束与阶段

固定锚点的原始存档坐标（ID、x、y）：

```json
[[1,0,1],[2,6,-1.5],[3,14,-1.5],[4,20,1]]
```

事件顺序是红车 A → 液压阶段 B → 船和甲虫共同进入 C 阶段。不要误认为船先通过、甲虫再单独出发。下层中桥位于 y=-1.5，初始跨越 x=6.1～13.9。两侧固定上层坡道连接岸上锚点，供后续甲虫通行。

材料上限：路面 10、钢材 4、绳子 4；本设计使用路面 10、木材 69、液压杆 4，未用钢材或绳子。

## 结构

- 两座木桁架塔以 x=6、14 的下层固定锚点为基础，与直接连接岸上锚点的侧坡道构成稳定结构。
- 每侧两根初始长度 3 m 的串联液压杆，`rate=0.5`。在液压阶段收缩，总计将中桥抬升约 3 m。
- 中桥为 4 段路面，上方三角桁架和沿桥面的木材提高刚度。初始两端与平台留有小间隙，避免把待移动桥面直接固定到下层锚点。
- 左、右固定坡道分别使用 3 段路面。中桥抬升后与坡道衔接，船从桥下通过，甲虫沿上层路线到终点。

第一版把侧坡道通过很短的铰接件连到岸上锚点，红车阶段便坍塌。最终版将坡道直接连到固定锚点，并加强坡道与塔架的连接，模拟通过。此经验不能替代对其他关卡的结构分析。
